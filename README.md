# GateHinge

GateHinge is a real-time network orchestrator that leverages distributed processing to optimize load-balancing across multiple controllers.

GateHinge is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/karanjamoses/GateHinge.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

GateHinge is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
